# Working on Keymarchy

Prepare changes on a branch and open a pull request for review. The maintainer,
Razu (@Razumasu), decides what is merged and released. Wait for explicit
maintainer approval before pushing to `main`, merging a pull request, publishing
a release, or changing repository settings.

Follow `CONTRIBUTING.md` for development and release checks. Keep README usage,
CLI help, and `docs/AGENT_SKILL.md` consistent with the implementation. Use
fictional data in screenshots and examples. Never change real PAM files or
security-key registrations as part of automated tests.
